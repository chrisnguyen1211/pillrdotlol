# pillr 1.1.0

Signed by Apple, and sign-ins on your terms.

- **Opens with a double-click.** pillr is now signed with a Developer ID and notarized by Apple.
- **pillr asks before reading other apps' sign-ins.** Reading Claude Code's and Antigravity's keychain items without a prompt is now a choice in Settings → General → Sign-ins, off by default.
- **Background Claude renewal can be turned off** in Settings → General → Sign-ins.
- **Every language shows again:** Français, 日本語, Português, Русский, 简体中文.

Coming from spyx or pillr 1.0.x? Download this DMG once and drag it over the old copy — updates come from this repository from now on.
